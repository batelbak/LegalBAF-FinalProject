# QBAF Legal Simulation

מערכת סימולציה אדברסרית מרובת-סוכנים לדיונים משפטיים מבוססי QBAF.

כרגע זה **שלד Java בלבד**. קורסר ואינטליג'יי עובדים על אותה תיקייה:

`C:\Users\sapir\qbaf-legal-sim`

## פתיחה באינטליג'יי

1. IntelliJ → **File → Open**
2. בחרי את התיקייה `C:\Users\sapir\qbaf-legal-sim`
3. אשרי פתיחה כפרויקט Maven (`pom.xml`)

## מבנה

- `agents` — תביעה, הגנה, שופט
- `qbaf` — גרף טיעונים כמותי והכרעה
- `simulation` — משפט רץ, אסטרטגיה, נקודות מפנה
- `data` — טעינת תיקים
- `optimization` — כיול משקלים
